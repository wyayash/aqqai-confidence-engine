Task 2 — Add inter-model agreement scoring
This is a signal unique to AQQAI that no single-model system can produce. After collecting all 5 responses, measure how much they agree with each other.

How to build it:
- Embed all 5 responses using sentence-transformers
- Compute pairwise cosine similarity between all response pairs
- Average all pairwise similarities → agreement score (0 to 1)
- High agreement (above 0.75) = strong confidence signal — the models converge on the same answer
- Low agreement (below 0.40) = ambiguous query or models are uncertain

Where it plugs in:
- Add `agreement_score` to the output of `process_confidence_request()`
- When agreement is high, the Bayesian weights can be applied more aggressively
- When agreement is low, weights should be more conservative (keep responses more equal)

Add this to `bayesian_confidence_layer2.py`.
